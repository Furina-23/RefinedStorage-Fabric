# Fabric 能量接口人工测试

状态：待用户人工测试。本文由助手提供，所有游戏操作由用户执行。

## 准备

- 使用 Minecraft 1.20.1、Fabric Loader、Fabric API 和包含本次修改的 Refined Storage Fabric。
- 使用现有测试实例，加入支持 Team Reborn Energy API 的发电机、电缆和充电设备；记录这些模组的名称和版本。
- 使用普通控制器、便携网格、无线网格、无线流体网格及无线合成监视器。安装 Addons 时另测无线合成网格。
- 为普通控制器连接最小存储网络，使其能够消耗能量。测试存档先备份。
